# DEMO TEXT SAMPLES (frontend examples only - not training data)

> These CSVs and `demo_data.py` are legacy leftovers from the removed
> TF-IDF / scikit-learn pipeline. They are NOT loaded by the backend:
> all analysis is routed through the Groq API only.

`demo_news.csv` and `demo_reviews.csv` are generated by
[`backend/ml/data/demo_data.py`](../data/demo_data.py) from sentence
templates. They are kept only as text samples — the backend never trains on
or loads them (Groq-only engine).

## Using a real dataset

Not applicable — the local training pipeline was removed. Provide
`GROQ_API_KEY` and all analysis (news / reviews / general content)
is routed through the Groq API (`POST {base}/chat/completions`).
