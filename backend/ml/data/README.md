# DEMO TRAINING DATA

> **This directory contains DEMO DATA, not production data.**

`demo_news.csv` and `demo_reviews.csv` are generated by
[`backend/ml/data/demo_data.py`](../data/demo_data.py) from sentence
templates. They exist so the application can run end-to-end out of the box.
The UI labels models trained on them as **"Demo-trained model"**.

## Using a real dataset

Provide a CSV with two columns — `label,text`:

| dataset | labels |
|---|---|
| News | `real`, `misinformative` |
| Reviews | `genuine`, `suspicious` |

Then either:

1. Set environment variables and retrain:

   ```bash
   set TRUTHLENS_NEWS_DATA=D:\path\to\real_news.csv
   set TRUTHLENS_REVIEWS_DATA=D:\path\to\real_reviews.csv
   python ml/train_news.py
   python ml/train_reviews.py
   ```

2. Or replace the CSVs in this folder (keep the same column names) and retrain.

Suggested public datasets: LIAR / FakeNewsNet (news), or any labelled
review-fraud dataset (e.g. with genuine/deceptive labels). Map their labels to
the ones above before training.
